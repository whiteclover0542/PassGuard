# PassGuard

비밀번호가 얼마나 안전한지, 유출된 적은 없는지 확인하고 어떻게 바꾸면 되는지 알려주는 웹앱입니다.
보안에 익숙하지 않은 사람(가족·친구)도 쓸 수 있게 쉬운 말로 결과를 보여줍니다.

**사용하기:** https://whiteclover0542.github.io/PassGuard/

## 기능

- **강도 검사**: 약함 / 보통 / 강함과 그렇게 판정한 이유를 보여줍니다. 입력하는 동안 미리 보기가 바뀝니다.
- **한국 사용자에게 흔한 패턴**: 영문 자판으로 친 한글(안녕 → `dkssud`), 생년월일, 전화번호, 흔한 이름의 로마자도 잡아냅니다.
- **추측 시간**: 해킹 프로그램이 비밀번호를 알아내는 데 걸리는 대략적인 시간을 보여줍니다. [zxcvbn](https://github.com/dropbox/zxcvbn)으로 단어·이름·흔한 비밀번호를 반영합니다.
- **유출 확인**: [Have I Been Pwned](https://haveibeenpwned.com/Passwords)의 공개 유출 목록에서 몇 번 발견됐는지 알려줍니다.
- **개선 안내**: 바꾸는 방법과 네이버·카카오·구글·애플 계정 설정 바로 가기를 보여줍니다.
- **안전한 비밀번호 만들기**: 대문자·소문자·숫자·기호를 섞은 16자를 만들어 줍니다.
- **계정 보안 체크리스트**: 6가지 질문으로 내 계정 보안 습관을 점검합니다.
- **큰 글씨 모드**, **다크 모드**(시스템 설정을 따름)

## 비밀번호를 보내지 않는 방법

- 비밀번호는 브라우저 안에서만 다루고, 어디에도 저장하지 않습니다(localStorage·쿠키·콘솔 모두 없음).
- 유출 확인은 [k-익명성](https://haveibeenpwned.com/API/v3#SearchingPwnedPasswordsByRange) 방식입니다. 브라우저에서 비밀번호의 SHA-1 해시를 만든 뒤 **앞 5자리만** 보내고, 돌아온 목록과의 대조는 브라우저에서 합니다.
- `Add-Padding` 헤더로 응답에 가짜 항목을 섞어, 응답 크기로 해시 범위를 짐작할 수 없게 합니다.
- 외부로 나가는 요청은 `api.pwnedpasswords.com/range/XXXXX`뿐입니다. zxcvbn도 저장소에 함께 두어 같은 주소에서 불러옵니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면, 스타일, 스크립트) |
| `zxcvbn.js` | 추측 시간 계산 라이브러리 (zxcvbn 4.4.2, MIT) |
| `check.js` | 강도 판정·추측 시간·비밀번호 만들기 셀프 체크 |
| `PLAN.md` / `PROGRESS.md` | 기획과 진행 기록 |

## 로컬에서 실행

```sh
python -m http.server 8000   # http://localhost:8000 접속
node check.js                # 셀프 체크, "ok"가 나오면 통과
```

`file://`로 열면 브라우저의 해시 기능(`crypto.subtle`)이 동작하지 않으니 위처럼 로컬 서버로 여세요.
